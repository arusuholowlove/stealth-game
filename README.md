Silent Stacks — a top-down stealth game you play in the browser. The archive closes at midnight: steal three files, slip past three patrolling guards with visible vision cones, hide behind the bookshelves, and reach the exit unseen. Guards learn your scent slowly — a detection meter that fills gives you room to break line of sight and recover — and a thrown noisemaker (click) can pull a guard off their route. WASD or arrows to move, Shift to run (loud), click to throw.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests: everything is static files under `game/`.
